# 可补充的标准 PDF 线索

这些链接是当前可公开检索到的候选资料入口，建议下载前确认来源、版权和版本有效性。项目没有自动把这些 PDF 放入 `data/pdf/`，避免把真实标准全文随作品集上传。

| 标准编号 | 名称 | 线索 |
| --- | --- | --- |
| JJG 875-2019 | 数字压力计检定规程 | https://img.antpedia.com/standard/files/pdfs_ora/20210902/JJG%20875-2019.pdf |
| JJG 882-2019 | 压力变送器检定规程 | https://img.antpedia.com/standard/files/pdfs_ora/20210202/JJG%20882-2019.PDF |
| JJF 1008-1987 | 压力计量名词术语及定义 | https://img.antpedia.com/standard/files/pdfs_ora/CN-JJF/f15/JJF%201008-1987.pdf |
| JJG 34-2022 | 指示表检定规程 | 可从中国计量测试学会培训资料页、食品伙伴网、分析测试百科网等入口继续核验 |
| JJG 21-2008 | 千分尺检定规程 | 可从食品伙伴网、相关计量机构下载页等入口继续核验 |

使用建议：

1. 面试作品集仓库只保留 Demo 文档与代码。
2. 本地演示时，将已确认可使用的 PDF 放入 `data/pdf/`。
3. 在页面点击 `PDF → Markdown`，再点击 `重新构建知识库`。
4. 真实业务规则请按正式 JJG/JJF/GB 文件补充到 `config/rules.yaml`。
